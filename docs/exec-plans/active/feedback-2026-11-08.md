## Request 2026-11-09: dictation ducking at once and smooth

- USER: the sound should go down smoothly, not in one jump, and at once when the dictation key (right ⌥) goes
  down. Before: 0.25 s hold wait + ~0.1 s microphone + the start sound (Bottle, 0.77 s), then one jump to 5 %.
- Now `Dictation.pressed()` ducks on key-down (hold mode); a tap, ⌥+letter, a failed start or the watch going away
  brings it back. `VolumeControl` fades: down 0.3 s, up 0.4 s, smoothstep, a 60 Hz timer only while it runs; a new
  press during the fade up reverses from where it is and keeps the first `from`. Trade-off: the start sound now plays
  at 5 %; ⌥+letter dips the sound slightly (to ~88 % at 80 ms) and brings it back.
- Verified: scratch harness with the real `Volume.swift` on the built-in output (0.688 → 0.050 in ~310 ms, back in
  ~410 ms; chord-like restore at 80 ms; reversal mid-fade; quit-restore at once; a level set by hand during the duck
  is kept; final level 0.688, saved state nil). Build 70 installed; the user tried it ("лучше в разы", smooth).
- Released as v71 (Nook 1.71, commit be5b409, notarized; plain DMG) on 2026-11-09; main and develop at be5b409.
