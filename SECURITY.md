# Security / Безопасность

**Report a vulnerability privately:** the "Security" tab of this repository → "Report a vulnerability".
Please do not open a public issue for it. You get an answer within a few days.

**О уязвимости сообщай приватно:** вкладка «Security» этого репозитория → «Report a vulnerability».
Не открывай для этого публичный issue. Ответ придёт в течение нескольких дней.

Only the latest release gets fixes. / Исправления выходят только для последней версии.

What matters most / Что особенно важно:
- anything that lets another process approve an agent's request or read Nook's data;
- anything that makes the updater install a build not signed with Nook's certificate;
- leaks of clipboard, notes or notification content.
